# GNU dd — шпаргалка

`dd` копирует поток байтов между файлами и устройствами. В Linux входит в GNU Coreutils.

## Практика на обычных файлах

В пустом каталоге создайте образ размером 8 МиБ. В примерах `set -C` в подоболочке включает защиту от перезаписи существующего файла при перенаправлении `>`.

```bash
(set -C; dd if=/dev/zero bs=1M count=8 status=progress > demo.img)
```

```bash
(set -C; dd if=demo.img bs=1M conv=fsync status=progress > copy.img)
```

```bash
cmp -- demo.img copy.img
```

Совпадающие файлы дают код выхода `0` и пустой вывод. Для независимой сверки сохраните или сравните контрольные суммы.

```bash
sha256sum -- demo.img copy.img
```

## Параметры

| Параметр | Назначение |
|---|---|
| `if=` / `of=` | Источник и назначение. По умолчанию stdin и stdout |
| `bs=1M` | Размер блока. `M` означает МиБ, `MB` означает десятичный мегабайт |
| `count=3` | Число входных блоков |
| `skip=2` / `seek=2` | Пропуск входных или выходных блоков |
| `iflag=fullblock` | Накапливает полные входные блоки при чтении из конвейера |
| `conv=notrunc` | Сохраняет прочие участки существующего выходного файла |
| `conv=fsync` | Синхронизирует выходной файл перед завершением |
| `status=progress` | Показывает прогресс копирования |

Копирование до 3 МиБ начиная со смещения 2 МиБ.

```bash
(set -C; dd if=demo.img bs=1M skip=2 count=3 > part.img)
```

## Образы дисков и ошибки

Для образа проверьте модель, размер и точки монтирования через `lsblk`. Источник должен быть защищён от активной записи или представлен согласованным снимком. Сохраняйте образ на другом диске. При записи на устройство `of=` может уничтожить разделы и данные. Сверьте направление копирования перед запуском.

| Ошибка | Действие |
|---|---|
| `cannot overwrite existing file` | Выберите новое имя выходного файла |
| `No space left on device` | Проверьте место на диске назначения и размер неполной копии |
| `Permission denied` | Проверьте права на источник и назначение |
| `Input/output error` | Проверьте состояние носителя. Для восстановления с проблемного диска используйте GNU ddrescue |

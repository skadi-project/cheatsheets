# pacman — шпаргалка

## 1. Что это и зачем

`pacman` — основной пакетный менеджер Arch Linux и его производных систем. Он синхронизирует базы пакетов, устанавливает зависимости и обновляет систему. В Debian и Ubuntu используйте APT. AUR — отдельный пользовательский репозиторий, для него нужен помощник или ручная сборка PKGBUILD.

## 2. Установка

`pacman` входит в базовую установку Arch Linux. Проверка версии не требует `sudo`.

```bash
pacman --version
```

Не удаляйте `pacman` из рабочей системы. В WSL устанавливайте Arch-дистрибутив отдельно и выполняйте команды внутри него. Для графических программ можно рассмотреть Flatpak, но это не замена управлению системными пакетами.

## 3. Особенности по ОС

- `pacman -Syu` обновляет базы и систему в одной операции. Частичные обновления не поддерживаются.
- В Arch пакетные имена и содержимое меняются быстрее, чем в стабильных Debian/Ubuntu выпусках. Читайте новости Arch перед крупным обновлением.
- Пользовательский репозиторий AUR не является официальным репозиторием Arch. Проверяйте `PKGBUILD` до сборки и не запускайте неизвестные скрипты с правами администратора.
- Сторонние репозитории и смешивание пакетов разных архитектур могут нарушить зависимости.

## 4. Быстрый старт

Обновите систему, найдите пакет `curl`, установите его и проверьте.

```bash
sudo pacman -Syu
pacman -Si curl
sudo pacman -S --needed curl
curl --version
```

Команда `-Syu` может обновить много пакетов и попросить подтверждение. Прочитайте список до согласия.

## 5. Основные команды

### Поиск и сведения

| Команда | Что делает | Пример |
|---|---|---|
| `-Ss` | Ищет пакет в синхронизированных базах | `pacman -Ss nginx` |
| `-Si` | Показывает сведения о доступном пакете | `pacman -Si curl` |
| `-Qs` | Ищет среди установленных пакетов | `pacman -Qs curl` |
| `-Qi` | Показывает сведения об установленном пакете | `pacman -Qi curl` |
| `-Ql` | Показывает файлы пакета | `pacman -Ql curl` |
| `-Qo` | Определяет пакет-владельца файла | `pacman -Qo /usr/bin/curl` |
| `-Qdt` | Показывает зависимости-сироты | `pacman -Qdt` |
| `-Qe` | Показывает явно установленные пакеты | `pacman -Qe` |

### Установка и удаление

| Команда | Что делает | Пример |
|---|---|---|
| `-S` | Устанавливает пакет и зависимости | `sudo pacman -S git` |
| `-R` | Удаляет пакет | `sudo pacman -R package` |
| `-Rs` | Удаляет пакет и ненужные зависимости | `sudo pacman -Rs package` |
| `-Rns` | Удаляет пакет, зависимости и конфигурационные файлы | `sudo pacman -Rns package` |
| `-U` | Устанавливает локальный пакет или URL | `sudo pacman -U ./package.pkg.tar.zst` |
| `-Sc` | Удаляет неустановленные кэшированные пакеты | `sudo pacman -Sc` |
| `-Scc` | Очищает весь кэш пакетов | `sudo pacman -Scc` |

### Обновление и базы

| Команда | Что делает | Пример |
|---|---|---|
| `-Sy` | Обновляет базы без обновления системы | `sudo pacman -Sy` |
| `-Su` | Обновляет пакеты по уже загруженным базам | `sudo pacman -Su` |
| `-Syu` | Обновляет базы и систему | `sudo pacman -Syu` |
| `-Syyu` | Принудительно скачивает базы и обновляет систему | `sudo pacman -Syyu` |
| `-Fy` | Обновляет базу поиска файлов, если включена | `sudo pacman -Fy` |
| `-F` | Ищет файл в базе пакетов | `pacman -F /usr/bin/curl` |

Не используйте `-Sy` отдельно перед установкой пакета. Это создаёт состояние частичного обновления. Если базы повреждены или зеркало сменилось, `-Syyu` применяйте осознанно.

## 6. Конфигурация

Главный файл — `/etc/pacman.conf`. Зеркала находятся в `/etc/pacman.d/mirrorlist`. Кэш пакетов хранится в `/var/cache/pacman/pkg/`. Включайте официальные репозитории только согласно конфигурации конкретного выпуска Arch.

```ini
[core]
Include = /etc/pacman.d/mirrorlist

[extra]
Include = /etc/pacman.d/mirrorlist
```

После изменения зеркал запускайте `sudo pacman -Syu`. Не удаляйте подписи и не отключайте проверку пакетов без ясной причины.

## 7. Полезные приёмы

- Перед обновлением проверьте свободное место через `df -h` и прочитайте новости Arch.
- Узнайте владельца команды через `pacman -Qo "$(command -v command_name)"`.
- Для удаления сирот сначала просмотрите список `pacman -Qdt`, затем удаляйте только действительно ненужные пакеты.
- Не используйте `--noconfirm` в интерактивной работе, если не проверили точный список операций.
- Для AUR сначала прочитайте `PKGBUILD`, после чего собирайте пакет обычным пользователем и устанавливайте готовый пакет через `pacman`.

## 8. Частые ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `failed to synchronize all databases` | Недоступно зеркало или неверно настроено время | Проверьте сеть, время, mirrorlist и попробуйте другое зеркало |
| `target not found` | Пакет отсутствует в включённых репозиториях | Проверьте имя и выполните `pacman -Ss` |
| `failed to commit transaction` | Конфликт файлов или зависимостей | Прочитайте конфликт, проверьте владельцев через `pacman -Qo` и не используйте принудительную перезапись без понимания причины |
| `key could not be looked up remotely` | Проблема с keyring | Обновите пакет keyring по официальной инструкции Arch |
| Частичное обновление | Использовался `-Sy` без полного обновления | Выполните полное `sudo pacman -Syu` и не смешивайте версии |
| `you cannot perform this operation unless you are root` | Операция меняет систему | Добавьте `sudo`, если это допустимо и ожидаемо |

# Python — основы

## Быстрый старт

Используйте Python 3. На Windows и macOS установщик доступен на [python.org](https://www.python.org/downloads/). В Ubuntu/Debian интерпретатор поставляется пакетом `python3`, в Arch — пакетом `python`.

Сохраните пример как `main.py`.

```python
def total(values):
    result = 0
    for value in values:
        result += value
    return result


if __name__ == "__main__":
    values = [2, 3, 5]
    print(total(values))
```

В Windows с Python Launcher выполните команду ниже.

```bash
py -3 main.py
```

В Linux и macOS используйте `python3`.

```bash
python3 main.py
```

Программа выведет `10`.

## Типы данных

| Тип | Пример | Назначение |
|---|---|---|
| `NoneType` | `value = None` | Единственный объект `None`, обозначающий отсутствие значения |
| `bool` | `ready = True` | Логическое значение |
| `int` | `count = 42` | Целое число произвольной точности |
| `float` | `price = 1.5` | Число с плавающей точкой |
| `complex` | `z = 2 + 3j` | Комплексное число |
| `str` | `name = "Ada"` | Неизменяемая строка Unicode |
| `bytes` | `data = b"raw"` | Неизменяемая последовательность байтов |
| `bytearray` | `data = bytearray(b"raw")` | Изменяемая последовательность байтов |
| `list` | `items = [1, 2, 3]` | Изменяемая упорядоченная последовательность |
| `tuple` | `point = (3, 4)` | Неизменяемая упорядоченная последовательность |
| `range` | `numbers = range(3)` | Последовательность целых чисел без хранения всех элементов |
| `dict` | `user = {"name": "Ada"}` | Отображение ключей в значения |
| `set` | `unique = {1, 2, 3}` | Неупорядоченное множество уникальных элементов |
| `frozenset` | `unique = frozenset({1, 2})` | Неизменяемое множество |

## Синтаксис

| Конструкция | Пример | Назначение |
|---|---|---|
| Основные типы | `n = 3; price = 1.5; ready = True; name = "Ada"` | Хранят числа, логическое значение и строку |
| Отсутствие значения | `result is None` | Проверяет, является ли объект `None` |
| Список | `items = [1, 2]; items.append(3)` | Хранит изменяемую последовательность |
| Кортеж | `point = (3, 4); x, y = point` | Хранит фиксированную последовательность и распаковывает её |
| Словарь | `user = {"name": "Ada"}; user.get("name")` | Хранит пары ключ–значение |
| Множество | `unique = {1, 2}; unique.add(3)` | Хранит уникальные элементы |
| Индексация и срез | `items[0]`, `items[-1]`, `items[:2]` | Берёт первый, последний или первые два элемента |
| Условие | `if n > 0: print(n)` | Выполняет блок по условию |
| Диапазон | `for i in range(3): print(i)` | Перебирает числа от 0 до 2 |
| Включение списка | `[x * x for x in items if x > 0]` | Собирает новые значения с фильтром |
| Функция | `def greet(name="World"): return f"Hello, {name}!"` | Задаёт параметр по умолчанию и форматирует строку |
| Импорт | `from pathlib import Path` | Импортирует объект из стандартной библиотеки |

## Ошибки, файлы и изменяемые объекты

```python
from pathlib import Path

try:
    text = Path("notes.txt").read_text(encoding="utf-8")
    print(text)
except FileNotFoundError:
    print("notes.txt is missing")
```

- Отступы определяют блоки. Используйте четыре пробела на уровень.
- `=` присваивает значение, `==` сравнивает значения, `is` проверяет идентичность объектов. Для `None` используйте `is None`.
- `b = a` для списка привязывает второе имя к тому же объекту. `b = a.copy()` создаёт поверхностную копию.
- Для изменяемых аргументов по умолчанию используйте `None` и создавайте список внутри функции. Значение аргумента по умолчанию вычисляется один раз при объявлении функции.
- Если открываете файл через `open`, используйте `with`, чтобы файл закрылся при выходе из блока.
- Проверка `if __name__ == "__main__"` запускает основной блок при прямом запуске файла.

# C — основы

## Быстрый старт

Сохраните пример как `main.c`. Примеры используют C17. Для сборки нужен GCC или Clang. На Ubuntu/Debian GCC входит в `build-essential`, на Arch — в `base-devel`, на macOS Clang входит в Xcode Command Line Tools, на Windows подходит GCC из MSYS2 UCRT64 или WSL.

```c
#include <stdio.h>
#include <stddef.h>

int sum(const int values[], size_t count) {
    int total = 0;
    for (size_t i = 0; i < count; ++i) {
        total += values[i];
    }
    return total;
}

int main(void) {
    int values[] = {2, 3, 5};
    size_t count = sizeof values / sizeof values[0];
    printf("%d\n", sum(values, count));
    return 0;
}
```

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic main.c -o demo.exe
```

```bash
./demo.exe
```

Расширение `.exe` удобно для запуска из Windows и допустимо на Linux и macOS. Для Clang замените `gcc` на `clang`. Программа выведет `10`.

## Типы данных

| Тип | Пример | Назначение |
|---|---|---|
| `char` | `char ch = 'A';` | Один байт для символа или части байтовой строки |
| `signed char` / `unsigned char` | `unsigned char byte = 255;` | Малое целое со знаком или без знака |
| `short` | `short count = 10;` | Целое число меньшего диапазона |
| `int` | `int count = 42;` | Основной целочисленный тип |
| `long` / `long long` | `long long total = 1000000LL;` | Целое число увеличенного диапазона |
| `float` | `float ratio = 0.5f;` | Число с плавающей точкой одинарной точности |
| `double` | `double price = 1.5;` | Число с плавающей точкой двойной точности |
| `_Bool` | `_Bool ready = 1;` | Логическое значение `0` или `1` |
| `void` | `void log_message(void);` | Отсутствие значения или отсутствие параметров в прототипе |
| `size_t` | `size_t length = sizeof(int);` | Беззнаковый тип для размеров и индексов |
| Массив | `int values[3] = {1, 2, 3};` | Фиксированная последовательность элементов одного типа |
| `struct` | `struct Point { int x; int y; };` | Составной тип с именованными полями |
| `enum` | `enum State { READY, DONE };` | Набор целочисленных именованных констант |

## Синтаксис

| Конструкция | Пример | Что делает |
|---|---|---|
| Типы | `int n = 3; double x = 1.5; char ch = 'a';` | Хранят целое, дробное число и символ |
| Константа | `const int limit = 10;` | Запрещает присваивание через это имя |
| Условие | `if (n > 0) { ++n; } else { n = 0; }` | Выбирает ветку |
| Цикл | `while (n > 0) { --n; }` | Повторяет блок, пока условие истинно |
| Массив | `int data[3] = {1, 2, 3};` | Хранит элементы одного типа, индексы начинаются с нуля |
| Строка | `char text[] = "hello";` | Хранит символы и завершающий `\0` |
| Указатель | `int *p = &n; *p = 7;` | Хранит адрес и позволяет изменить `n` |
| Структура | `struct Point { int x; int y; };` | Объединяет поля разных или одинаковых типов |
| Перечисление | `enum State { READY, DONE };` | Даёт имена целочисленным константам |
| Прототип | `int add(int a, int b);` | Объявляет сигнатуру функции |

## Память и типичные ошибки

- Аргументы передаются по значению. Чтобы изменить переменную вызывающего кода, передайте её адрес.
- Параметр `const int values[]` фактически является указателем. Передавайте длину отдельно. Формула с `sizeof` для числа элементов работает там, где переменная ещё имеет тип массива.
- Проверяйте границы массива. Для строки выделяйте место под `\0`.
- При использовании `malloc` из `<stdlib.h>` проверьте результат на `NULL` и освободите память через `free` ровно один раз.
- Сравнивайте содержимое строк через `strcmp` из `<string.h>`. Оператор `==` для указателей сравнивает адреса.
- Используйте `%d` для `int` и `%zu` для `size_t` в `printf`.

# Rust — основы

## Быстрый старт

Установите стабильный инструментарий через [rustup](https://rustup.rs/). Для стандартной сборки MSVC в Windows нужны Visual Studio Build Tools с компонентами C++ и Windows SDK.

Сохраните пример как `main.rs`. Примеры используют редакцию Rust 2024, доступную начиная с Rust 1.85.

```rust
fn sum(values: &[i32]) -> i32 {
    let mut total = 0;
    for &value in values {
        total += value;
    }
    total
}

fn main() {
    let values = [2, 3, 5];
    println!("{}", sum(&values));
}
```

```bash
rustc --edition=2024 main.rs -o demo.exe
```

```bash
./demo.exe
```

Программа выведет `10`.

## Типы данных

| Тип | Пример | Назначение |
|---|---|---|
| `bool` | `let ready: bool = true;` | Логическое значение |
| `i8` … `i128` | `let count: i32 = 42;` | Знаковые целые фиксированного размера |
| `u8` … `u128` | `let byte: u8 = 255;` | Беззнаковые целые фиксированного размера |
| `isize` / `usize` | `let index: usize = 0;` | Целое, связанное с размером указателя |
| `f32` / `f64` | `let ratio: f64 = 1.5;` | Числа с плавающей точкой |
| `char` | `let symbol: char = 'Ж';` | Unicode-скаляр, заключённый в одинарные кавычки |
| `&str` | `let text: &str = "hello";` | Заимствованный строковый срез |
| `String` | `let text = String::from("hello");` | Владеющая изменяемая UTF-8 строка |
| Массив `[T; N]` | `let values: [i32; 3] = [1, 2, 3];` | Последовательность фиксированного размера |
| Срез `&[T]` | `let part: &[i32] = &values[..2];` | Заимствованный участок последовательности |
| `Vec<T>` | `let values: Vec<i32> = vec![1, 2];` | Владеющий список переменной длины |
| Кортеж `(T, U)` | `let point: (i32, i32) = (3, 4);` | Группа значений разных типов |
| `Option<T>` | `let value: Option<i32> = None;` | Значение `Some` или отсутствие `None` |
| `Result<T, E>` | `let result: Result<i32, std::num::ParseIntError> = "42".parse();` | Успех `Ok` или ошибка `Err` |
| `struct` / `enum` | `struct Point { x: i32 }` | Пользовательские составные типы |

## Синтаксис

| Конструкция | Пример | Назначение |
|---|---|---|
| Переменная | `let n: i32 = 3;` | Создаёт неизменяемую привязку с явным типом |
| Изменяемая переменная | `let mut n = 3; n += 1;` | Разрешает последующее присваивание |
| Условие | `let label = if n > 0 { "yes" } else { "no" };` | Выбирает значение по условию |
| Диапазон | `for i in 0..3 { println!("{i}"); }` | Перебирает числа от 0 до 2 |
| Массив и срез | `let a = [1, 2, 3]; let part = &a[..2];` | Хранят элементы и дают доступ к их части |
| Вектор | `let mut data = vec![1, 2]; data.push(3);` | Хранит список переменной длины |
| Строка | `let text = String::from("hello");` | Хранит текст UTF-8 с владением |
| Структура | `struct Point { x: i32, y: i32 }` | Объединяет именованные поля |
| Перечисление | `enum State { Ready, Done }` | Задаёт допустимые варианты |
| `match` | `match n { 0 => "zero", _ => "other" }` | Сопоставляет значение с шаблонами |
| `Option<T>` | `let first = data.first();` | Представляет значение `Some` или его отсутствие `None` |
| `Result<T, E>` | `let number = "42".parse::<i32>();` | Представляет успех `Ok` или ошибку `Err` |

## Владение и типичные ошибки

- Присваивание `let b = a;` переносит владение для `String` и `Vec`. Для типов с `Copy`, например `i32`, значение копируется.
- `&value` даёт доступ для чтения, `&mut value` — исключительный доступ для изменения. Пока действует изменяемое заимствование, другие активные заимствования того же значения запрещены.
- Последнее выражение блока без `;` задаёт результат блока. В `sum` это `total`.
- Сопоставляйте `Option` и `Result` через `match`. Оператор `?` передаёт ошибку вызывающему коду из функции с совместимым возвращаемым типом.
- Для доступа по индексу с проверкой используйте `data.get(i)`. Для обхода символов строки используйте `.chars()`, поскольку `String` хранит UTF-8.

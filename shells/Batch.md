# Windows Batch — шпаргалка

## 1. Что это и зачем

Batch — сценарии `.bat` и `.cmd` для `cmd.exe`. Используйте их для простых Windows-задач и поддержки старых сценариев. Для работы с объектами и структурированными данными подходит PowerShell.

## 2. Установка

`cmd.exe` входит в Windows 10/11 и обновляется вместе с ОС. Его можно открыть из меню «Пуск» или выбрать профиль Command Prompt в Windows Terminal. На Linux и macOS для работы в той же среде используйте Windows в виртуальной машине. Системный `cmd.exe` оставьте на месте.

```bat
cmd /d /c ver
```

## 3. Особенности ОС

Внутри файла Batch переменная цикла записывается `%%F`, а в интерактивном `cmd.exe` — `%F`. Для простых сценариев используйте CRLF и ASCII. Для не-ASCII текста проверьте кодировку файла и кодовую страницу терминала.

## 4. Быстрый старт

Сохраните `hello.cmd`. Пример принимает обычное имя в кавычках.

```bat
@echo off
setlocal
set "name=%~1"
if not defined name set "name=World"
echo Hello, "%name%"!
exit /b 0
```

Выполните в `cmd.exe`.

```bat
hello.cmd "Ada Lovelace"
```

## 5. Основной синтаксис

| Конструкция | Назначение | Пример |
|---|---|---|
| `@echo off` | Скрывает печать исполняемых строк | `@echo off` |
| `rem` | Добавляет комментарий | `rem Check arguments` |
| `set` | Задаёт переменную | `set "name=Ada"` |
| `set /a` | Считает целое выражение | `set /a total=2+3` |
| `set /p` | Читает строку | `set /p "name=Name? "` |
| `%~1` | Первый аргумент без внешних кавычек | `set "path=%~1"` |
| `%~dp0` | Диск и каталог скрипта с завершающим разделителем | `pushd "%~dp0"` |
| `if defined` | Проверяет наличие переменной | `if defined name echo Name set` |
| `if exist` | Проверяет путь | `if exist "notes.txt" type "notes.txt"` |
| `if errorlevel` | Проверяет код, больший или равный порогу | `if errorlevel 1 exit /b 1` |
| `for` | Перебирает файлы | `for %%F in (*.txt) do echo "%%F"` |
| `for /l` | Перебирает числа | `for /l %%N in (1,1,3) do echo %%N` |
| `call` | Вызывает Batch-файл или подпрограмму и возвращается | `call :report` |
| `goto` | Переходит к метке | `goto :eof` |
| `setlocal` | Ограничивает изменения окружения до `endlocal` или конца файла | `setlocal` |
| `exit /b` | Завершает скрипт или подпрограмму с кодом | `exit /b 1` |

## 6. Конфигурация

Настройки отдельного сценария удобно объявлять в его начале. `setlocal` ограничивает изменения окружения. У `cmd.exe` флаг `/d` отключает запуск настроенных команд AutoRun для нового сеанса.

```bat
@echo off
setlocal EnableExtensions DisableDelayedExpansion
set "output_dir=%~dp0output"
```

## 7. Полезные приёмы

- Ставьте кавычки вокруг путей с пробелами.
- Используйте `pushd "%~dp0"` и `popd`, чтобы работать относительно файла сценария.
- В блоке `(…)` подстановки `%var%` могут раскрыться до выполнения блока. С `setlocal EnableDelayedExpansion` используйте `!var!` для чтения текущего значения. При обработке текста с `!` учитывайте, что включённое раскрытие может изменить данные.
- Проверяйте `if errorlevel 1` сразу после команды и сверяйте её соглашение о кодах выхода.
- Для отладки временно включите `echo on` после строк с чувствительными аргументами.

## 8. Частые ошибки

| Симптом | Причина | Решение |
|---|---|---|
| Цикл работает только в терминале | В файле использован один `%` | В файле используйте `%%F` |
| Подстановка в блоке показывает старое значение | `%var%` раскрылась заранее | Включите отложенное раскрытие для этого блока и используйте `!var!` |
| Не выполнены строки после другого `.cmd` | Скрипт запущен без `call` | Вызовите его через `call` |
| Закрылось окно консоли | Выполнен `exit` | Используйте `exit /b` |

# Zsh — шпаргалка

## 1. Что это и зачем

Zsh подходит для интерактивной работы с автодополнением и для скриптов с расширенными шаблонами и массивами. Для сценариев, которые должны работать через `/bin/sh`, используйте POSIX-синтаксис.

## 2. Установка

| ОС | Установка | Удаление |
|---|---|---|
| Ubuntu/Debian | `sudo apt install zsh` | `sudo apt remove zsh` |
| Arch | `sudo pacman -Syu zsh` | `sudo pacman -R zsh` |
| macOS | Встроенный `/bin/zsh` или `brew install zsh` | `brew uninstall zsh` для копии Homebrew |
| Windows | Установите пакет внутри WSL | Удалите пакет внутри WSL |

```bash
zsh --version
```

Версию сверяйте с сайтом проекта. `-Syu` обновляет систему. Перед удалением Zsh, выбранного login-оболочкой, переключитесь на установленную оболочку.

## 3. Особенности ОС

В macOS Zsh используется по умолчанию для новых учётных записей начиная с Catalina. В Linux запуск `zsh` в терминале позволяет попробовать оболочку без смены системных настроек. Сценарии сохраняйте с окончаниями LF.

## 4. Быстрый старт

Сохраните `hello.zsh`.

```zsh
#!/usr/bin/env zsh
names=("${1:-World}" Zsh)
for name in "${names[@]}"; do
    printf 'Hello, %s!\n' "$name"
done
```

```bash
zsh hello.zsh 'Ada Lovelace'
```

## 5. Основной синтаксис

| Конструкция | Назначение | Пример |
|---|---|---|
| `name=value` | Присваивание | `name='Ada Lovelace'` |
| `export` | Передаёт переменную потомкам | `export EDITOR=vi` |
| `"$@"` | Передаёт аргументы по отдельности | `printf '%s\n' "$@"` |
| `$(…)` | Подставляет вывод команды | `dir=$(pwd)` |
| `[[ … ]]` | Проверяет условие | `[[ -f $path ]]` |
| `(( … ))` | Проверяет числовое выражение | `(( count > 0 ))` |
| `for` | Перебирает значения | `for n in 1 2 3; do print -r -- "$n"; done` |
| `files=(…)` | Создаёт массив | `files=('a b.txt' c.txt)` |
| `$files[1]` | Выбирает первый элемент при стандартных настройках | `print -r -- "$files[1]"` |
| `typeset -A` | Объявляет словарь | `typeset -A counts; counts[ready]=2` |
| `**/` | Ищет рекурсивно | `files=(**/*.txt(N))` |
| `(N)` | Даёт пустой список при отсутствии совпадений | `files=(*.txt(N))` |
| `source` | Выполняет файл в текущей оболочке | `source ./settings.zsh` |
| `setopt` | Включает опцию | `setopt pipefail` |
| `$pipestatus` | Коды выхода команд последнего конвейера | `print -r -- "$pipestatus[@]"` |

## 6. Конфигурация

Пользовательские файлы находятся в `$ZDOTDIR`, по умолчанию в домашнем каталоге. `.zshrc` читается в интерактивном сеансе, `.zprofile` при входе, `.zshenv` при каждом обычном запуске Zsh. Пример `.zshrc`.

```zsh
autoload -Uz compinit
compinit
alias ll='ls -l'
```

## 7. Полезные приёмы

- Проверяйте синтаксис через `zsh -n hello.zsh`.
- Используйте `zsh -f` для проверки поведения без большинства файлов запуска.
- Используйте `print -r --` для буквального вывода строк.
- Заключайте пути в кавычки при передаче другим оболочкам и инструментам.
- Изучайте шаблоны через раздел `Filename Generation` в руководстве.

## 8. Частые ошибки

| Симптом | Причина | Решение |
|---|---|---|
| `no matches found` | Шаблон не нашёл файлов | Используйте `(N)` для пустого списка или кавычки для буквального шаблона |
| Пропущен первый элемент | Индекс как в Bash | Начинайте с 1 при стандартных настройках Zsh |
| Скрипт работает лишь из терминала | Он зависит от `.zshrc` | Объявите необходимые переменные и функции в скрипте |

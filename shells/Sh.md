# POSIX sh — шпаргалка

## 1. Что это и зачем

`sh` — стандартный интерфейс командной оболочки POSIX. Подходит для коротких переносимых скриптов. Для массивов используйте Bash, для сложной обработки данных — Python.

## 2. Установка

- **Ubuntu/Debian, Arch** — `/bin/sh` уже поставляется системой. Для отдельной реализации `dash` установите пакет `dash` через `apt` или `pacman`. Удалять можно только дополнительную реализацию после проверки зависимостей. Системный `/bin/sh` оставьте на месте.
- **macOS** — используйте встроенный `/bin/sh`.
- **Windows** — используйте `sh` внутри WSL. Git Bash также предоставляет `sh`, но окружение отличается от Linux.

У `sh` нет общей команды проверки версии. Проверьте запуск.

```bash
sh -c 'printf "%s\n" OK'
```

## 3. Особенности ОС

В Ubuntu/Debian `/bin/sh` обычно указывает на Dash, в Arch — на Bash. Успешный запуск в одной реализации не гарантирует переносимость расширений. Сохраняйте Unix-скрипты с окончаниями LF.

## 4. Быстрый старт

Сохраните `hello.sh`.

```sh
#!/bin/sh
name=${1:-World}
printf 'Hello, %s!\n' "$name"
```

```bash
sh hello.sh 'Ada Lovelace'
```

## 5. Основной синтаксис

| Конструкция | Назначение | Пример |
|---|---|---|
| Присваивание | Создаёт переменную | `name=Ada` |
| `export` | Передаёт переменную дочерним процессам | `export LANG=C` |
| `"$@"` | Передаёт все аргументы по отдельности | `printf '%s\n' "$@"` |
| `$#` | Число аргументов | `printf '%s\n' "$#"` |
| `${x:-default}` | Подставляет значение для пустой или незаданной переменной | `${1:-World}` |
| `$(…)` | Подставляет вывод команды | `dir=$(pwd)` |
| `$((…))` | Вычисляет целое число | `n=$((n + 1))` |
| `[ … ]` | Проверяет условие | `[ -f "$path" ]` |
| `if` | Ветвление по коду выхода | `if [ -r "$path" ]; then printf 'Readable\n'; fi` |
| `case` | Сопоставляет шаблоны | `case "$1" in *.txt) printf 'Text\n';; esac` |
| `for` | Перебирает аргументы | `for arg do printf '%s\n' "$arg"; done` |
| `read` | Читает строку | `IFS= read -r line` |
| Функция | Группирует команды | `greet() { printf 'Hello, %s\n' "$1"; }` |
| `>` / `>>` | Перезаписывает или дополняет файл | `printf 'OK\n' >> report.txt` |
| `2>&1` | Направляет stderr туда же, куда stdout | `command > report.txt 2>&1` |
| `exit` | Завершает скрипт с кодом | `exit 1` |

## 6. Конфигурация

Для login-оболочки обычно используется `~/.profile`. Поведение системных файлов зависит от реализации. Сценарий должен задавать нужные переменные самостоятельно.

```sh
export EDITOR=vi
```

## 7. Полезные приёмы

- Заключайте подстановки аргументов и путей в двойные кавычки.
- Используйте `printf` для предсказуемого форматирования.
- Для проверки синтаксиса используйте `sh -n hello.sh`, для трассировки — `sh -x hello.sh`.
- Проверяйте важные операции через `if` или `|| exit 1`.
- Для совместимости со старыми реализациями не рассчитывайте на `pipefail`.

## 8. Частые ошибки

| Симптом | Решение |
|---|---|
| `unexpected "("` | Уберите массивы Bash или запускайте Bash-скрипт через `bash` |
| `missing ]` | Отделите `[` и `]` пробелами от аргументов |
| `bad interpreter` | Проверьте shebang, путь к оболочке и окончания LF |
| Аргумент с пробелами разделился | Используйте `"$var"` или `"$@"` |

# Bash — шпаргалка

## 1. Что это и зачем

Bash — оболочка GNU с массивами, шаблонами и средствами отладки. Подходит для автоматизации команд Linux. Для переносимых системных скриптов используйте [POSIX sh](Sh.md).

## 2. Установка

| ОС | Установка | Удаление дополнительной копии |
|---|---|---|
| Ubuntu/Debian | Обычно установлен. Пакет `bash` | Системный пакет оставьте на месте |
| Arch | Обычно установлен. Пакет `bash` | Системный пакет оставьте на месте |
| macOS | Встроенный Bash или `brew install bash` | `brew uninstall bash` для копии Homebrew |
| Windows | WSL для Linux-окружения или Git for Windows для Git Bash | Git for Windows удаляется через «Установленные приложения» |

```bash
bash --version
```

Версия пакета зависит от ОС. Последний стабильный выпуск сверяйте на сайте GNU.

## 3. Особенности ОС

На macOS встроенный Bash обычно версии 3.2. Ассоциативные массивы и `mapfile` требуют Bash 4+. Проверьте, какой интерпретатор выбирает `PATH`. В Git Bash пути и набор утилит отличаются от Linux. Для скриптов используйте LF.

## 4. Быстрый старт

Сохраните `hello.bash`.

```bash
#!/usr/bin/env bash
names=("${1:-World}" "Bash")
for name in "${names[@]}"; do
    printf 'Hello, %s!\n' "$name"
done
```

```bash
bash hello.bash 'Ada Lovelace'
```

## 5. Основной синтаксис

| Конструкция | Назначение | Пример |
|---|---|---|
| `name=value` | Присваивает строку | `name='Ada Lovelace'` |
| `export` | Передаёт переменную потомкам | `export EDITOR=vi` |
| `${1:-…}` | Задаёт значение по умолчанию | `name=${1:-World}` |
| `"$@"` | Передаёт аргументы по отдельности | `printf '%s\n' "$@"` |
| `$(…)` | Подставляет stdout | `dir=$(pwd)` |
| `[[ … ]]` | Проверяет условие | `[[ $name == A* ]]` |
| `(( … ))` | Проверяет арифметическое выражение | `(( n > 0 ))` |
| `case` | Выбирает ветку по шаблону | `case $1 in start) printf 'Start\n';; esac` |
| `for` | Перебирает элементы | `for n in 1 2 3; do printf '%s\n' "$n"; done` |
| `array=(…)` | Создаёт индексированный массив | `files=('a b.txt' c.txt)` |
| `"${array[@]}"` | Раскрывает элементы по отдельности | `printf '%s\n' "${files[@]}"` |
| `declare -A` | Создаёт словарь в Bash 4+ | `declare -A counts=([ready]=2)` |
| `local` | Объявляет переменную внутри функции | `local name=$1` |
| `read -r` | Читает строку | `IFS= read -r line` |
| `source` | Выполняет файл в текущей оболочке | `source ./settings.bash` |
| `set -o pipefail` | Учитывает ошибку команды внутри конвейера | `set -o pipefail` |
| `trap` | Выполняет действие при выходе или сигнале | `trap 'printf "Done\n" >&2' EXIT` |

## 6. Конфигурация

Интерактивный Bash без login обычно читает `~/.bashrc`. Login-оболочка читает первый доступный из `~/.bash_profile`, `~/.bash_login`, `~/.profile` после системного профиля. Пример для `~/.bashrc`.

```bash
alias ll='ls -l'
export EDITOR=vi
```

## 7. Полезные приёмы

- Проверяйте синтаксис через `bash -n hello.bash`.
- `bash -x hello.bash` выводит команды и раскрытые аргументы. Не используйте трассировку там, где в аргументах есть секреты.
- Используйте массивы для списков путей, особенно если имена содержат пробелы.
- Проверяйте ожидаемые ошибки явно. `set -e` имеет исключения, включая команды, проверяемые в `if`.
- Перед запускаемыми сторонними файлами проверяйте содержимое, особенно перед `source`.

## 8. Частые ошибки

| Симптом | Решение |
|---|---|
| `declare: -A: invalid option` | Выберите Bash 4+ |
| `unexpected token '('` | Запускайте скрипт через `bash` |
| `bash\r` в ошибке | Сохраните файл с LF |
| Пробелы в имени файла разделили аргумент | Используйте `"$path"` или `"${files[@]}"` |
